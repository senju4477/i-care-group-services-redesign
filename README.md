# I Care Group Services — Website Redesign

Complete source of the separate I Care Group Services redesign, including all 23 pages, 11 expanded service guides, original branding, responsive layouts, accessible navigation, service filters, FAQs and contact tools.

Preview: https://i-care-inspired-redesign.walkersaint402.chatgpt.site

## Run and check

Use Node.js 22. No third-party application packages are required.

```sh
npm run verify
npm start
```

The build creates `dist/`. The Node server listens on `process.env.PORT` (default 3000) and binds to `0.0.0.0`. Hostinger Node.js hosting can use `npm run build` and `npm start`. A static host can serve `dist/`.

## Preview behaviour

Forms remain in review mode by default: sample enquiries are checked locally, without sending or storing messages. The preview is excluded from search indexing. Telephone, email, maps and WhatsApp links use the existing business details.

For a real launch, confirm the final domain, indexing and email delivery configuration before switching review mode off. Nothing in this repository upload changes any hosted website or existing repository.

## Source structure

- `src/`: page templates, business data, expanded service information, accessibility widgets and HTTP handling.
- `public/assets/`: complete image variants, logos, fonts, styles and browser scripts.
- `sources/`: original images retained for future editing.
- `scripts/`: static build and route/asset checks.
- `tests/`: existing functional tests.
- `dist/`: generated by `npm run build`; contains the ready-built static website.
- `ASSET-SOURCES.json` and `THIRD-PARTY-NOTICES.md`: image provenance and third-party notices.

This GitHub export has its own identity. ChatGPT hosting identifiers, temporary QA pages, credentials and local repository metadata are excluded.
